# OpenCart Login Automation

Selenium WebDriver (Java) script that automates the login flow on [OpenCart](https://www.opencart.com/), including PIN verification.

## Flow

1. Open opencart.com in Chrome
2. Click **Login**
3. Enter email and password
4. Click the **Login** button
5. Enter PIN and click **Continue**

## Tech Stack

Java, Selenium WebDriver, ChromeDriver, Maven

## Run

Run the `main` method in `Main.java` from your IDE.
